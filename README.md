# Codyssey Mission 3 — Mini NPU Simulator

26올인원 1기 미션 3의 행렬 연산 기반 십자가(Cross) / X 패턴 분류 시뮬레이터입니다.

## 주요 기능
- 행렬 곱셈 누산(MAC) 연산
- 행렬 크기 및 입력값 검증
- Cross와 X 패턴 점수 계산 및 분류
- JSON 데이터셋 로드와 케이스별 PASS/FAIL 결과 출력
- 3×3, 5×5, 13×13, 25×25 크기 벤치마크
- 부동소수점 오차를 고려한 epsilon 비교

## 프로젝트 구성
- `main.py`: MAC 연산, 패턴 분류, 데이터 분석 및 벤치마크
- `data.json`: 현재 포함된 데모 데이터셋
- `test_main.py`: 행렬, 라벨, 데이터셋, 벤치마크 자동 테스트
- `SUBMISSION_STATUS.md`: 제출 전 점검 사항

## 실행 방법
Python 3.10 이상을 권장합니다.

```bash
python main.py --analyze
```

자동 테스트:

```bash
python -m unittest -v
```

## 데이터셋 주의
현재 `data.json`은 코드 동작 확인용 데모 데이터입니다. 교육 과정에서 제공된 공식 원본 데이터셋이 있다면 해당 파일로 교체한 뒤 전체 케이스를 다시 검증해야 합니다. 데모 데이터 통과를 공식 데이터 통과로 표현하지 않습니다.
