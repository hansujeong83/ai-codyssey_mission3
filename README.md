# Mission 3 — Mini NPU Simulator

순수 Python 이중 반복문으로 MAC(Multiply-Accumulate)을 계산하고, Cross(십자가)와 X 패턴의 점수를 비교하는 콘솔 프로그램입니다.

## 실행
```bash
python main.py
```
- 메뉴 1: 3×3 필터 A/B와 패턴을 한 줄씩 입력합니다. 숫자 개수/형식을 검증하고 필터 사용 여부를 확인한 뒤 결과를 출력합니다.
- 메뉴 2: `data.json`을 분석하고 케이스별 PASS/FAIL, 전체 통계, 크기별 성능 표를 출력합니다.
- CLI: `python main.py --analyze`, `python main.py --benchmark`
- 데이터 경로: `python main.py --analyze --data ./data.json`

## 구현 요약
1. `mac(pattern, filter)`: 외부 수치 라이브러리 없이 중첩 반복문으로 같은 위치 원소를 곱하고 누적합니다.
2. `validate_matrix`: 정사각형, 동일 크기, 숫자형, 유한값을 검사합니다.
3. `normalize_label`: `+`/`cross`를 `Cross`, `x`를 `X`로 정규화합니다.
4. `classify`: 두 점수 차이가 epsilon(`1e-9`) 미만이면 `UNDECIDED`로 판정합니다.
5. JSON 케이스 키 `size_N_idx`에서 크기를 추출하고, 해당 크기의 필터를 연결합니다.
6. 잘못된 케이스는 프로그램 전체를 중단하지 않고 케이스 단위 FAIL 및 실패 사유로 기록합니다.
7. 사용자 입력 모드는 MAC을 10회 반복 측정하고 평균 시간을 표시합니다.
8. 성능 분석은 3×3, 5×5, 13×13, 25×25에서 반복 측정하고 평균 시간(ms)과 원소 연산 횟수 N²를 표시합니다.

## 결과 리포트 및 분석
- MAC은 각 행과 열을 한 번씩 순회하므로 N×N 행렬에서 곱셈과 누적 덧셈을 각각 N²회 수행합니다.
- 따라서 입력 크기가 N일 때 시간 복잡도는 O(N²)입니다.
- 입력 행렬을 이미 메모리에 보유한 상태에서 누적 변수만 사용하므로 추가 공간 복잡도는 O(1)입니다.
- 행렬 한 변의 길이가 2배가 되면 원소 방문 횟수는 4배가 됩니다.
- 실제 실행 시간은 CPU, 운영체제, Python 버전, 백그라운드 작업에 따라 달라집니다.
- 그러므로 서로 다른 PC에서 측정한 절대 시간만으로 성능을 단정하지 않습니다.
- 샘플을 여러 번 반복하고 평균값을 사용해 일시적인 측정 편차를 줄입니다.
- `+`와 `cross`를 같은 `Cross` 라벨로 통일해 데이터 표기 차이로 인한 오판을 방지합니다.
- `x` 역시 내부 표준 라벨 `X`로 통일해 필터 키와 expected 비교 기준을 일치시킵니다.
- 부동소수점 계산은 미세한 오차가 발생할 수 있으므로 점수 차이가 1e-9 미만이면 동점(UNDECIDED)으로 처리합니다.
- 동점은 Cross 또는 X로 억지 분류하지 않으며 expected가 Cross/X인 케이스에서는 FAIL로 집계합니다.
- 스키마 오류, 크기 불일치, 잘못된 라벨은 로직 오류와 구분해 해당 케이스의 실패 사유로 출력합니다.
- 공식 데이터에서 FAIL이 발생하면 먼저 키/라벨/행렬 구조를 확인하고, 다음으로 MAC 계산과 epsilon 비교 정책을 점검합니다.

## 실제 로컬 검증 결과

```bash
python -m py_compile main.py test_main.py

python main.py --analyze
```

- Python 문법 검사: 통과
- 자동 단위 테스트: 18개 통과, 0개 실패

| 행렬 크기 | 평균 MAC 시간(ms) | 원소 연산 횟수(N²) |

측정 시간은 해당 PC의 실행 환경에서 얻은 참고값이며, 다른 환경에서는 달라질 수 있습니다.

## 공식 데이터 관련 주의
현재 저장소의 `data.json`은 과제 명세에 맞춰 직접 구성한 자체 검증 데이터입니다. 별도의 강사 제공 원본 파일을 받지 못한 상태이므로, 이를 공식 배포 데이터라고 표시하지 않습니다. 5×5, 13×13, 25×25 각각에 Cross/X 기본 패턴과 약한 잡음이 추가된 패턴을 두어 총 12개 케이스를 검증합니다. 추후 강사 제공 JSON이 별도로 확인되면 `python main.py --analyze --data 경로/data.json`으로 별도 검증할 수 있습니다.
